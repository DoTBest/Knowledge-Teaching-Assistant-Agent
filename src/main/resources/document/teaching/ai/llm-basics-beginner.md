# 大模型基础入门

## 适用人群
对AI/大模型感兴趣，希望了解基本概念和使用方法的开发者。

## 什么是大语言模型（LLM）
大语言模型（Large Language Model）是基于海量文本数据训练的AI模型，能够理解和生成自然语言。代表性模型包括GPT-4、Claude、Qwen（通义千问）等。

LLM的核心能力：文本生成、问答、翻译、代码生成、摘要、推理等。

## Prompt工程基础
Prompt（提示词）是与AI交互的输入，好的Prompt能显著提升AI输出质量。

**Prompt的组成部分：**
- System Prompt（系统提示）：定义AI的角色和行为规范
- User Message（用户消息）：用户的具体问题或指令
- Assistant Message（助手消息）：AI的历史回复（多轮对话）

**Prompt编写原则：**
1. 明确角色：告诉AI它是谁，有什么能力
2. 清晰指令：具体说明要做什么，不要模糊
3. 提供上下文：给出必要的背景信息
4. 指定格式：说明期望的输出格式

```
# 差的Prompt
"解释Spring"

# 好的Prompt
"你是一位Java教学专家。请用简单易懂的语言，结合代码示例，
向一个有Java基础但没学过Spring的开发者解释Spring IoC的概念。
回答控制在300字以内，代码示例要完整可运行。"
```

## Token与计费
Token是LLM处理文本的基本单位，大约4个英文字符或1.5个中文字符等于1个Token。

**Token的重要性：**
- 模型有上下文窗口限制（如128K Token）
- API按Token计费（输入Token + 输出Token）
- Token数量影响响应速度

**优化Token使用：**
- 精简System Prompt，去除冗余描述
- 使用RAG替代将全部文档塞入Prompt
- 合理设置对话历史窗口大小

## 模型参数
调整模型参数可以控制输出风格。

**Temperature（温度）：**
- 范围：0.0 ~ 2.0
- 低温（0.0~0.3）：输出更确定、保守，适合代码生成、数据提取
- 高温（0.7~1.5）：输出更随机、创意，适合创意写作、头脑风暴

**Top-P（核采样）：**
- 控制候选词的概率质量，通常与Temperature配合使用
- 推荐值：0.9（保留90%概率质量的词汇）

```yaml
# Spring AI 配置示例
spring:
  ai:
    dashscope:
      chat:
        options:
          model: qwen-plus
          temperature: 0.7   # 适中创意度
          top-p: 0.9
          max-tokens: 2048   # 最大输出长度
```

## 常见问题
Q: 什么是幻觉（Hallucination）？
A: 幻觉是指LLM生成看似合理但实际错误的内容。解决方案：使用RAG提供真实知识库、要求模型引用来源、对关键信息进行验证。

Q: 如何选择合适的模型？
A: 考虑：任务复杂度（简单任务用小模型省成本）、语言（中文任务优先国产模型）、隐私要求（敏感数据用本地模型）、延迟要求（实时场景选响应快的模型）。
